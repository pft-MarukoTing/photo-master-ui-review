IMAGE 1 = SOURCE (原始手部照片，尚未套用新指甲風格前)。
IMAGE 2 = REFERENCE (提供指甲風格的照片)。
IMAGE 3 = RESULT (經過指甲風格移植後的輸出圖)。

請評估 RESULT 是否同時符合：
1. 手的部分（手勢、姿勢、膚色、戒指/飾品、袖口服裝、背景）與 SOURCE 一致，沒有被改動。
2. 指甲的部分（形狀、顏色、圖案、亮粉/金屬箔等元素）成功換成了 REFERENCE 的風格。

只要有一項明顯不符合，verdict 就是 "bad"；兩項都做到才是 "good"。
reason 用繁體中文簡短說明理由（包含兩點各自的判斷）。
