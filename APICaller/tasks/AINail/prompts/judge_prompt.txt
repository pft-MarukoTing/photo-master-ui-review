IMAGE 1 = SOURCE (原始手部照片，尚未套用新指甲風格前)。
IMAGE 2 = REFERENCE (提供指甲風格的照片)。
IMAGE 3 = RESULT (經過指甲風格移植後的輸出圖)。

請逐一檢查 RESULT 是否同時符合以下四項：

1. 手的部分（手勢、姿勢、膚色、戒指/飾品、袖口服裝、背景）與 SOURCE 一致，沒有被改動。
   - 特別注意：RESULT 是否其實是把 REFERENCE 的整隻手（連手勢、膚色、背景一起）直接剪貼過來，
     而不是把 SOURCE 的手保留、只換掉指甲。若整隻手明顯來自 REFERENCE 而非 SOURCE，此項不通過。

2. 指甲的色調以及材質效果整體上成功換成了 REFERENCE 的風格，不能只對到主題顏色。
   - 特別檢查材質/工藝是否有被簡化或遺漏：若 REFERENCE 的指甲帶有立體浮雕、鑲嵌飾品（水鑽、金屬物件）、
     或亮粉暈染（ombre/dip）等特殊效果，RESULT 也必須呈現對應的立體感、鑲嵌質感或暈染漸層，
     而不能被簡化成扁平的純色印花、細線描邊，或只保留局部顏色卻遺漏了暈染/漸層範圍。
   - 若 RESULT 把 REFERENCE 原本立體/鑲嵌/暈染的效果拍扁、簡化或大範圍遺漏，此項不通過。

3. 指甲圖案是否畫在正確的一面：根據 SOURCE 手部在畫面中的姿勢與朝向，判斷每根手指的指甲板（甲面）
   實際朝向哪一側。RESULT 的美甲圖案必須出現在同一側，不能出現在手指的另一面（例如明顯是指腹、
   手掌側，或跟 SOURCE 手指朝向不合理地對不上）。若圖案位置跟手指的實際朝向兜不起來，此項不通過。

4. 逐顆指甲的執行細節正確。這一項務必對 SOURCE 手上「每一根」手指分別檢查一遍再下結論，
   不要只看整體印象就判斷：
   - 圖案/顏料是否畫在指甲板範圍內，沒有溢出蓋到指腹（手指肉墊）或周圍皮膚上。
   - 每顆指甲上的圖案本身是否清晰可辨識（例如畫的是鬼就要看得出鬼的輪廓/表情，
     而不是一團模糊不成形的色塊或色斑；圖案中鑲嵌的小物件，例如水鑽、金屬飾件，也要清楚成形，
     不能糊成一團）。
   - 只要任何一根手指有上述任一種問題，此項就不通過，並在 reason 中指出是哪根手指、什麼問題。

只要四項中有任何一項明顯不符合，verdict 就是 "bad"；四項都做到才是 "good"。
reason 用繁體中文簡短說明理由，並清楚指出是哪一項（1/2/3/4）不符合、具體錯在哪裡（例如哪根手指、
什麼樣的錯誤），不要只用「風格不對」這種籠統說法帶過。
